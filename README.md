# 拾光影视

从搜剧网站公开页面和实际请求分析出发，独立实现的影视聚合搜索与站内播放器。

## 已实现

- 并行查询非凡、红牛、新浪、金鹰、量子、魔都、速播、豪华八个公开资源接口，按片名与年份合并结果。
- 获取影片详情、直接播放线路、分页搜索与结果分类筛选。
- 优先动态加载 hls.js 播放 HLS，浏览器不支持 MSE 时回退到原生 HLS；支持播放器自带全屏、拖动和音量控制。
- 线路切换、剧集选择、剧集自动下一集；影片语言版本由用户手动选择。
- 浏览器本地收藏、最近搜索和观看进度。
- 腾讯公开弹幕：按片名、年份与分集匹配，分段加载，支持开关、透明度、密度、时间偏移与自定义全屏。
- 响应式桌面侧栏、手机底部导航、播放器加载错误提示与重试。

不依赖 souju3.com 的私有后端；没有复制其账号体系、解析票据、广告或标识。

## 开发

使用 Node.js 22.13+ 与 pnpm：

```sh
pnpm install
pnpm dev
```

本地默认地址：http://127.0.0.1:5173/ 。构建：`pnpm build`。

检查：`pnpm exec tsc --noEmit`；解析与来源降级测试：`node --experimental-strip-types --test tests/catalog.test.mjs`。

弹幕解析测试：`node --experimental-strip-types --test tests/danmaku.test.mjs`。

## 当前边界

首页展示上游最新内容，不是本站算法推荐；分类筛选针对已加载结果，可继续加载更多。收藏和历史在本设备浏览器保存，不跨设备同步。暂无账号、云端数据库、管理后台、AI 对话搜索或搜剧专有解析线路。

缓存按实例短期保存 60 秒，最多 160 条；来源连接超时为 10 秒。服务端接口只请求固定来源，不提供任意 URL 代理。

从旧收藏或历史打开影片时，会尝试补全新增来源；加载更多搜索结果时会保留前面找到的版本。中文/数字季序号会归一化，但不同年份、不同季仍分别展示。

搜剧的“官方B/D/C/V、腾讯视频”等特殊线路使用其后端的临时票据解析，并非上述公开接口。当前未接入此类服务，也没有把普通来源伪装成“官方”。

## 弹幕

本站独立实现腾讯公开接口适配，没有调用搜剧私有弹幕后端，也没有借用其他应用的身份凭证。

`/api/danmaku` 提供白名单内的片名搜索、分集和弹幕分段读取。弹幕按视频的 currentTime 绘制到 Canvas；暂停时冻结，拖动后重新定位，倍速时跟随视频时钟。最多缓存在屏的六个分段，服务器结果缓存五分钟。

默认优先自动匹配相同片名、年份与集数；不明确时需在“弹幕设置”手动确认版本与分集。当前只覆盖腾讯上可读取的对应弹幕，不保证每部影片都有。片头、删减或版本不同可能导致时间差，可用时间偏移调整。没有发送弹幕功能。

点击播放器下方的“全屏”可保留弹幕层；系统原生画中画/独立视频窗口不能显示网页叠加层。浏览器不支持容器全屏时保留行内弹幕。

适配过程中核对了腾讯公开 JSON 响应及 [开源项目的接口说明](https://github.com/huangxd-/danmu_api)；本站适配器与 Canvas 渲染代码独立编写，未引入该项目代码、Cookie、签名或应用凭证。

### 清晰度优先
打开影片时并行检测当前/续播集的 HLS 主清单（每条最多3秒），按清单声明的最高分辨率排序。没有可读主清单时参考影片/线路明确的2160P、1080P等标注，未提供者显示未知，不把HLS或蓝光字样视为1080P。来源标注与清单实测分别显示。默认选首条并保留匹配集数/进度，不再优先旧线路。跨域限制、MP4及仅有媒体分片列表的HLS无法在此检测出分辨率；不保证编码质量或每条实际可播放。官方解析线路尚未接入。
